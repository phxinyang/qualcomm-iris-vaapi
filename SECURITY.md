# Security Policy

This project interfaces with kernel V4L2 devices and is experimental on
Qualcomm Iris hardware. A successful decode run is not a security guarantee;
keep the documented sandbox and fallback limitations in mind.

Please report vulnerabilities privately through GitHub's Security Advisories
feature when it is enabled for the repository. Do not include credentials,
private device addresses, or exploitable input samples in a public issue. If
private reporting is unavailable, open a minimal issue containing only the
project version and a non-sensitive reproduction outline.

There is no guaranteed response or supported-security-release schedule yet.
